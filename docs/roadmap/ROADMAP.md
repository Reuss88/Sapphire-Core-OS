# Sapphire Core OS Roadmap

## Current role of this roadmap

This roadmap tracks both:

- the Broker Operating System commercial sequence
- the governed architecture and runtime work that enable it

## Commercially ordered roadmap

1. Lock Broker OS business doctrine
2. Select the first market and internal venture
3. Define acquisition and network data model
4. Define pricing evidence model
5. Build the lead-to-settlement vertical slice
6. Add unified analytics
7. Prove one real transaction loop
8. Validate subscription tiering and commission rules
9. Add AI assistance under governance
10. Expand into additional markets and capabilities
