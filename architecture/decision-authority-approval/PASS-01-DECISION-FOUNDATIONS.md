# Module 8 — Pass 1: Decision Foundations

**Status:** Designed; pending final module consolidation.

## Purpose

Define what an organisational Decision is and distinguish it from related information and governance concepts.

## Core rule

```text
Work coordinates action.
Authority permits action.
Decisions determine action.
Approvals authorise action.
These are related, but they are never the same thing.
```

## Decision

A Decision is a governed determination that selects one permitted course of action from one or more alternatives.

A Decision has:

- subject;
- alternatives;
- outcome;
- decision maker;
- basis;
- decision time;
- consequences;
- rationale.

A Decision is separate from the action that implements it.

## Canonical distinctions

| Concept | Primary purpose |
|---|---|
| Observation | Record something noticed |
| Measurement | Quantify |
| Finding | Record an investigation result |
| Assessment | Evaluate |
| Recommendation | Suggest |
| Opinion | Express personal judgement |
| Advice | Guide |
| Validation | Verify correctness |
| Confirmation | Verify occurrence |
| Certification | Confirm compliance |
| Consent | Express voluntary agreement |
| Declaration | Formally disclose |
| Determination | Establish an official conclusion |
| Decision | Select organisational course |
| Approval | Grant organisational permission |

## Decision hierarchy

```text
Observation
→ Measurement
→ Finding
→ Assessment
→ Recommendation
→ Decision
→ Action
```

## Decision intent

A Decision may express:

- selection;
- permission;
- prohibition;
- prioritisation;
- classification;
- commitment;
- acceptance;
- deferral;
- escalation.

## Key boundaries

- Every Approval is a Decision.
- Not every Decision is an Approval.
- Recommendation says, “I think we should.”
- Decision says, “We will.”
- Confirmation is evidence, not permission.
- Validation is verification, not authority.
- Certification establishes compliance evidence.
- Consent is not organisational approval.
- Determination establishes an official conclusion.

## AI

AI may observe, analyse, assess, and recommend. AI does not become the Decision Maker unless explicitly permitted by the Authority Architecture.

## Principles

- DF-01 Decision changes organisational intent.
- DF-02 Decision is separate from action.
- DF-03 Recommendation is not Decision.
- DF-04 Approval is a specialised Decision.
- DF-05 Confirmation is evidence, not permission.
- DF-06 Validation is verification, not authority.
- DF-07 Assessment supports Decision.
- DF-08 Workflow coordinates Decisions.
- DF-09 Lifecycle applies Decisions.
- DF-10 Evidence informs Decisions.
- DF-11 AI may recommend.
- DF-12 Decision Maker remains explicit.
- DF-13 Alternatives remain identifiable.
- DF-14 Decision outcomes remain governed.
- DF-15 Decision history is immutable.
