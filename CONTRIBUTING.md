# Contributing

## Before making changes

Read:

- `README.md`
- `architecture/MASTER-ARCHITECTURE.md`
- `architecture/STATUS.md`
- `GOVERNANCE.md`
- `architecture-manifest.json`

## Contribution rules

1. Preserve canonical terminology.
2. Separate normative architecture from implementation guidance.
3. Do not collapse lifecycle state into workflow state.
4. Do not allow routing, assignment, access, or ownership to imply authority.
5. Preserve effective time, history, provenance, and evidence.
6. Record material decisions as ADRs.
7. Add tests for architecture conformance when implementation begins.
8. Mark reconstructed or provisional content clearly.
