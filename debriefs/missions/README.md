# Project Mission Records

This directory contains concise pointers for missions participating in the
Office debrief system. A record is not a second completion report.

Required frontmatter:

```yaml
mission_id:
project_report:
office_debrief:
issue:
pr:
merge_commit:
```

Use `TBD` or `UNKNOWN_REQUIRED` for evidence that is not established. Every
record must contain a canonical `office_debrief` link.
