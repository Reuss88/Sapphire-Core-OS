# Sapphire Design System

## Status
Authoritative cross-product design doctrine for Sapphire Core OS.

The current Director-approved product direction is defined by `actions-visual-direction-v1.md`. The approved Actions execution canvas is the visual and interaction baseline for HOME and future workspaces.

## Design intent
Sapphire must feel like a private commercial command environment for high-value brokerage, finance and asset acquisition. The emotional objective is **Quiet Power**: opulent, controlled, precise, institutional and intelligent.

The system must never feel like a generic CRM, gaming interface, consumer app or decorative analytics product.

## Pillars
1. **Luxury** — restrained materials, disciplined spacing, premium typography and deliberate motion.
2. **Institutional credibility** — trustworthy hierarchy, exact alignment, stable semantics and evidence-led presentation.
3. **Commercial intelligence** — the interface surfaces what matters, why it matters and what should happen next.
4. **Operational control** — status, authority, provenance and consequences remain visible.
5. **Cross-platform continuity** — the same commercial meaning must survive desktop, installed PWA and future Capacitor delivery.

## Material language
Sapphire uses a matte titanium visual language: deep blue-black foundations, graphite-navy surfaces, controlled sapphire accents, fine borders, limited glow and minimal transparency.

Glassmorphism is prohibited as a dominant material. Gradients, bloom and luminous effects are reserved for intelligence, realtime state, selected navigation and exceptional commercial emphasis.
