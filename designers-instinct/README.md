# Designers Instinct

Designers Instinct is the permanent UI/UX governance layer for Sapphire Core OS.

## Governing distinction

> Broker OS doctrine defines how the business operates.
>
> Designers Instinct defines how the business is experienced.

This directory governs how Sapphire Core OS presents commercial information, structures navigation, prioritises action, applies visual hierarchy, and translates operating doctrine into usable product surfaces.

It does not redefine business logic, ownership, authority, workflow, or commercial policy. Those remain governed by the relevant Broker OS and system doctrine.

## Permanent principles

- Sapphire is organised around Commercial Workspaces, not database objects.
- Every screen has one primary purpose and one dominant commercial question.
- Summary precedes detail.
- Drill-down replaces duplication.
- Commercial action outweighs decorative analytics.
- AI may recommend, explain, and prioritise, but never grants authority.
- Workflow state never implies permission.

## Files

- `dashboard-landing-principles.md` — doctrine for the commercial command centre.
- `product-surface-map.md` — permanent workspace architecture and ownership map.
- `navigation-philosophy.md` — principles governing movement through the product.
- `parity-laws-v0.md` — initial cross-product design laws.
- `roadmap.md` — path from Designers Instinct to a locked design system.

## Status

This directory is permanent design governance for the entire Sapphire Core OS product surface. Changes must preserve the distinction between operating doctrine and product experience.
