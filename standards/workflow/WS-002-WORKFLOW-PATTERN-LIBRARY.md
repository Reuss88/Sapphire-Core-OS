# WS-002 — Canonical Workflow Pattern Library

The approved pattern library contains 24 canonical patterns:

1. Intake and Triage
2. Evidence Collection
3. Research and Assessment
4. Human Review
5. Prepare and Approve
6. Multi-Review
7. Formal Decision
8. Approval
9. Authorised Execution
10. External Asynchronous Execution
11. Reconciliation
12. Work Queue Processing
13. Exception Resolution
14. Rework
15. Escalation
16. Cancellation and Closure
17. Compensation
18. Periodic Control
19. Notification and Acknowledgement
20. Long-Running Case Coordination
21. AI-Assisted Human Work
22. Deterministic Automated Routing
23. Transition-Oriented Workflow
24. Incident Response

Each implementation must document its adaptation and demonstrate conformance.
